Appendix A — Full Model Inventory Extended Tables
This appendix provides extended details for all pre-trained language models discussed in §3 and summarized in the main Table 1. Each entry reports:
  • Arch: Enc = encoder-only, Dec = decoder-only, E-D = encoder-decoder, MM = multimodal.
  • Strategy: CPT = continued pre-training; IFT = instruction fine-tuning; SFT = supervised fine-tuning; DPO = direct preference optimisation; RLHF = reinforcement learning from human feedback.
  • Benchmark results: BLURB (encoder-only); MedQA (4-option USMLE); MedMCQA; PubMedQA where reported.
  • OS: open-source status — ✓ publicly released, ~ partial/institutional, ✗ proprietary.
Results marked † are few-shot prompted; ‡ fine-tuned; ★ current SOTA on MedQA (4-option). n/a = not reported or evaluation setting incompatible.

Evaluation Protocol Note

Results across Tables A.1–A.4 are drawn from original papers and may not be directly comparable due to three primary sources of heterogeneity:
  1. MedQA variant — evaluated in both 3-option and 4-option formats across studies; the 4-option variant is harder and is the standard from 2022 onwards.
  2. Train/test splits — differ between the official Jin et al. (2021) release and community-reproduced splits.
  3. Few-shot prompt format — varies in number of examples (1–8), chain-of-thought structure, and system prompt content.
Scores should be interpreted as approximate rather than absolute rankings. The BLURB leaderboard (microsoft.github.io/BLURB) provides standardized encoder-only comparisons under a fixed evaluation protocol. All URLs verified December 2025; availability is subject to repository maintainer policies.
